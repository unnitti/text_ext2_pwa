# 클립보드 가공

iPhone의 사진에서 Live Text로 추출한 업무용 텍스트에서 필요한 정보만 골라내어 원하는 형식으로 정리하는 웹앱입니다.

상품코드, 날짜, 지번을 직접 찾아서 복사하고 정리하는 반복 작업을 줄이기 위해 만들었습니다.

**[앱 실행하기](https://unnitti.github.io/text_ext2_pwa/)**

## 사용 환경

- **iPhone + Safari 기준으로 개발 및 테스트**
- Android는 별도 테스트하지 않았습니다.
- 별도의 앱 설치 없이 브라우저에서 사용할 수 있습니다.
- 홈 화면에 추가하면 앱처럼 실행할 수 있습니다.

## 가장 편한 사용 방법

이 앱은 iPhone의 **사진 앱 → Live Text → 단축어 → 클립보드 가공** 흐름을 기본으로 사용합니다.

```text
사진
 ↓
iPhone Live Text
 ↓
텍스트 전달
 ↓
클립보드 가공
 ↓
상품코드 / 날짜 / 지번 추출
 ↓
결과를 클립보드에 복사
```

단축어를 사용하지 않고 직접 텍스트를 붙여넣어 사용하는 것도 가능합니다.

## 기본 사용법

### 방법 1. 클립보드 불러오기

1. 필요한 텍스트를 클립보드에 복사합니다.
2. 앱을 엽니다.
3. `클립보드 불러오기`를 누릅니다.
4. 필요한 정보가 자동으로 추출됩니다.
5. 결과를 확인합니다.
6. `결과 복사`를 눌러 다시 클립보드에 복사합니다.

### 방법 2. 직접 붙여넣기

입력창에 텍스트를 직접 붙여넣을 수도 있습니다.

텍스트를 붙여넣는 즉시 결과가 자동으로 처리됩니다.

## 추출 규칙

이 앱은 모든 텍스트를 이해하는 프로그램이 아닙니다.

현재 사용하는 업무 자료의 형식에 맞춰 정해진 규칙으로 필요한 내용을 찾습니다.

### 상품코드

`상품코드` 항목 오른쪽에 있는 상품코드를 찾아 추출합니다.

상품코드는 현재 업무 자료의 형식에 맞춰 다음과 같은 형태를 대상으로 합니다.

```text
영대문자로 시작하는 9글자 + 공백 + 3글자
```

예:

```text
ABC123456 XYZ
```

처럼 영문 대문자와 숫자가 섞인 문자열을 상품코드로 인식합니다.

상품코드의 구체적인 형식은 실제 업무 자료에 따라 변경될 수 있습니다.

9글자와 마지막 3글자 사이의 공백이 화면 폭이나 Live Text 인식 때문에 줄바꿈으로 들어간 경우에도 하나의 상품코드로 인식합니다.

또한 iPhone Live Text가 상품코드의 공백이나 줄바꿈을 다르게 인식하는 경우가 있으므로, 인식된 텍스트가 실제 상품코드와 일치하는지 확인하는 것이 좋습니다.

### 날짜

다음 형식의 날짜를 찾습니다.

```text
소비기한 YYYY-MM-DD
제조일자 YYYY-MM-DD
```

예:

```text
소비기한 2026-09-12
```

→

```text
소비 26.09.12 /
```

또는

```text
제조일자 2026-09-12
```

→

```text
제조 26.09.12 /
```

현재 날짜 인식은 `YYYY-MM-DD` 형식을 기준으로 합니다.

### 예외 처리되는 날짜 구간

`판매 가능`이 포함된 줄은 날짜 추출에서 제외됩니다.

해당 줄 바로 다음 줄도 함께 건너뜁니다.

이는 현재 사용하는 업무 자료의 특정 문구를 고려한 예외 규칙입니다.

### 지번

원문에서 다음과 같은 형태의 문자열을 찾습니다.

```text
11-영문/숫자-영문/숫자-영문/숫자...
```

추출된 결과는 앞의 `11-`을 제외하고 다음 형식으로 표시합니다.

```text
지번 XXXXX
```

같은 지번이 여러 번 발견되면 한 번만 출력합니다.

## 결과 순서

추출된 결과는 다음 순서로 정리됩니다.

```text
상품코드
날짜
지번
```

여러 개의 상품코드나 날짜가 발견되면 발견된 순서대로 표시됩니다.

## Live Text를 사용할 때 주의하세요

이 앱은 사진 자체를 OCR 처리하지 않습니다.

사진의 문자는 먼저 **iPhone Live Text가 인식**합니다.

따라서 다음과 같은 문제가 발생할 수 있습니다.

- 숫자와 영문자가 잘못 인식되는 경우
- 코드 중간의 공백이나 줄바꿈이 달라지는 경우
- 날짜의 기호가 다르게 인식되는 경우
- 글자가 흐리거나 작아서 일부가 누락되는 경우

앱이 처리하지 못한 경우에는 먼저 Live Text가 실제로 어떻게 인식했는지 확인해 보세요.

특히 상품코드는 한 글자만 잘못 인식되어도 다른 코드가 되거나 추출되지 않을 수 있습니다.

## 클립보드 접근이 되지 않는 경우

iPhone Safari의 보안 정책이나 브라우저 상태에 따라 클립보드 자동 읽기가 제한될 수 있습니다.

이 경우 입력창을 길게 눌러 직접 붙여넣어 보세요.

결과 복사 역시 클립보드 접근이 제한된 경우에는 결과를 직접 선택하여 복사할 수 있습니다.

## 보안 및 개인정보

별도의 서버나 데이터베이스를 사용하지 않고 브라우저에서 텍스트를 처리합니다.

단축어 등에서 `#t=` 방식으로 전달된 원문은 처리 후 주소창에 그대로 남지 않도록 정리합니다.

## 오프라인 사용

앱의 기본 파일은 서비스 워커를 통해 캐시됩니다.

따라서 기본적인 앱 화면은 오프라인에서도 불러올 수 있습니다.

다만 **클립보드와 같은 브라우저 기능은 인터넷 연결 여부와 별개로 브라우저의 보안 정책에 영향을 받을 수 있습니다.**

## 이 앱의 한계

이 앱은 특정 업무 자료를 빠르게 정리하기 위해 만든 특수 목적의 도구입니다.

다른 형식의 문서나 다른 종류의 상품코드에서는 원하는 결과가 나오지 않을 수 있습니다.

자동으로 추출된 결과가 항상 원본과 일치한다고 가정하지 말고, 중요한 업무에서는 원본과 결과를 확인해 주세요.

## 문제가 발생했을 때

문제가 발생했다면 가능하면 다음 내용을 함께 알려 주세요.

1. 원본 사진
2. Live Text가 실제로 인식한 텍스트
3. 앱에 입력된 텍스트
4. 기대한 결과
5. 실제 결과

특히 **Live Text 결과를 함께 알려 주는 것이 중요합니다.**

앱이 잘못 처리한 것인지, Live Text가 원문을 잘못 인식한 것인지 구분하는 데 도움이 됩니다.
