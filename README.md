# 클립보드 가공

iPhone의 사진 앱에서 추출한 **라이브 텍스트에서 필요한 정보만 자동으로 골라내고 원하는 형식으로 가공하는 간단한 웹앱**입니다.

업무용 사진에서 상품코드, 제조일자·소비기한, 지번 등의 정보를 일일이 찾아 복사하고 정리하는 번거로운 작업을 줄이기 위해 만들었습니다.

## 주요 기능

클립보드에 있는 원문에서 필요한 정보만 추출하여 정해진 형식으로 다시 만들어 줍니다.

### 상품코드 추출

`상품코드` 등의 업무 텍스트에 포함된 상품코드를 인식합니다.

- 영문 대문자와 숫자로 구성된 12자리 코드 추출
- `9자리 + 공백 + 3자리`로 나뉘어 인식된 코드도 하나로 결합
- 중복된 상품코드는 한 번만 출력

### 날짜 추출

다음 정보를 찾아 `26.09.12`와 같은 형식으로 변환합니다.

- `소비기한 YYYY-MM-DD` → `소비 26.09.12 /`
- `제조일자 YYYY-MM-DD` → `제조 26.09.12 /`

특정 `판매 가능` 관련 문구 뒤의 예외 구간은 추출 대상에서 제외합니다.

### 지번 추출

원문에서 지번 형태의 정보를 찾아 필요한 부분만 추출한 뒤

`지번 XXXXX`

형식으로 출력합니다.

### 결과 정리

추출한 정보는 다음 순서로 정리됩니다.

```text
상품코드
날짜
지번
```

가공된 결과는 버튼을 눌러 다시 클립보드에 복사할 수 있습니다.

## 사용 방법

### 기본 사용

1. 원문 텍스트를 클립보드에 복사합니다.
2. 앱에서 **클립보드 불러오기**를 누릅니다.
3. 필요한 정보가 자동으로 추출됩니다.
4. **결과 복사**를 눌러 가공된 결과를 클립보드에 복사합니다.

입력창에 직접 붙여넣는 방법도 사용할 수 있습니다. 붙여넣는 즉시 결과가 자동으로 처리됩니다.

### iPhone 라이브 텍스트와 함께 사용

이 앱은 iPhone 사진 앱의 **라이브 텍스트**와 함께 사용하는 것을 기본적인 작업 흐름으로 합니다.

```text
사진
 ↓
iPhone 라이브 텍스트
 ↓
단축어에서 텍스트 전달
 ↓
Clipboard Processor
 ↓
상품코드 / 날짜 / 지번 추출
 ↓
클립보드 복사
```

단축어에서 추출한 텍스트를 URL의 `#t=` 뒤에 담아 앱으로 전달하면, 앱을 열었을 때 자동으로 텍스트를 처리할 수 있습니다.

앱은 처리 후 URL에 전달된 원문이 주소창에 남지 않도록 주소를 정리합니다.

## PWA

이 프로젝트는 별도의 앱 설치 없이 브라우저에서 사용할 수 있는 **Progressive Web App(PWA)** 형태로 만들어졌습니다.

iPhone에서는 Safari에서 사용할 수 있으며, 홈 화면에 추가하면 독립적인 앱 형태로 실행할 수 있습니다.

서비스 워커를 이용해 주요 파일을 캐시하므로 앱의 기본 파일은 오프라인에서도 불러올 수 있습니다. 다만 클립보드 API 등의 브라우저 기능은 실행 환경에 따라 제한될 수 있습니다.

## 현재 지원 환경

- iPhone: 정상 작동 확인
- Android: 별도 기기 테스트 전

현재 프로젝트는 iPhone 사용을 중심으로 개발 및 테스트하고 있습니다.

## 기술 구성

- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)
- Service Worker
- Clipboard API
- URL Fragment (`#t=`)를 이용한 텍스트 전달

별도의 서버나 데이터베이스를 사용하지 않고 브라우저에서 텍스트를 처리합니다.

## 프로젝트 상태

현재 버전과 실제 테스트 결과, 알려진 문제 및 다음 작업은 [`PROJECT_STATUS.md`](./PROJECT_STATUS.md)에서 관리합니다.

AI를 이용한 프로젝트 개발 협업 규칙은 [`AI_RULES.md`](./AI_RULES.md)를 참고합니다.

## 주의사항

이 프로그램은 특정 업무에서 반복되는 텍스트 정리 작업을 줄이기 위해 만든 개인 프로젝트입니다.

현재 추출 규칙은 실제 사용 환경에 맞춰져 있으므로, 다른 형식의 텍스트에서는 원하는 결과가 나오지 않을 수 있습니다.
