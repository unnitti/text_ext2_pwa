# 클립보드 가공 PWA

iPhone Safari에서 클립보드의 업무용 텍스트를 가져와 상품코드, 소비기한/제조일자, 지번만 추출하고 정해진 형식으로 다시 클립보드에 복사하는 오프라인 PWA입니다.

## 현재 규칙

### 상품코드
- 12자리 영대문자/숫자 코드
- `MK`, `M`, `P` 계열
- `9자리 3자리`처럼 공백으로 나뉜 코드는 공백을 제거
- 동일 코드는 한 번만 출력

### 날짜
- `소비기한 YYYY-MM-DD` → `소비 YY.MM.DD /`
- `제조일자 YYYY-MM-DD` → `제조 YY.MM.DD /`
- `판매 가능`이 포함된 고정 문구 구간에서는 해당 줄과 다음 줄을 건너뜀
- `센터판매마감일`, `입고일자` 등은 추출하지 않음

### 지번
- `11-PC9-37-1` 등의 형식
- `11-` 제거
- `지번 PC9-37-1` 형식으로 출력
- 동일 지번은 한 번만 출력

## 실행
클립보드 API는 보안상 HTTPS 또는 localhost 환경이 필요합니다. GitHub Pages 같은 HTTPS 호스팅에 올려 iPhone Safari에서 열어 사용할 수 있습니다.
